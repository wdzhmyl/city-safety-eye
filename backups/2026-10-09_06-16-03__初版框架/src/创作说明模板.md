# 创作说明（移动云 AIGC 大赛 · 智慧城市方向）

> 按比赛要求填写：作品主题、所用工具/模型、创作流程、创新点。以下为模板，按需补充。

## 一、作品名称
城市安全之眼 —— 基于 YOLOv8 与多模态大模型的智慧城市安全分析 Demo

## 二、作品主题
智慧城市（AI 方向）。面向城市街景 / 监控场景，自动识别目标并生成结构化的安全事件分析报告，
辅助城市治理人员快速研判交通、人群聚集、设施占用及异常事件（烟火 / 积水 / 违停等）。

## 三、所用工具与技术
- 目标检测：YOLOv8n（Ultralytics，预训练权重，本地轻量推理）
- 报告生成：移动云 / 九天大模型（多模态，OpenAI 兼容接口，使用赛事提供的 Token 算力）
- 交互界面：Gradio（Python Web Demo）
- 开发语言：Python

## 四、创作流程
1. 需求拆解：城市安全治理需要"看得懂 + 说得清"的自动化能力。
2. 架构设计：检测层（YOLO，精确计数画框）+ 理解层（多模态大模型，语义报告）解耦。
3. 实现：检测输出中文标签与框坐标；连同原图送入云端大模型，生成"事件清单 / 风险研判 / 处置建议 / 结论"四段式报告。
4. 集成：Gradio 封装为可交互网页 Demo，支持上传图片一键分析。
5. 兜底：无云端 Key 时回退本地模板报告，保证可用性。

## 五、创新点
- 检测与生成解耦，兼顾精度与语义理解。
- 零训练开箱即用，可快速迁移到不同城市场景。
- 多模态大模型补充 YOLO 未覆盖的异常（烟火 / 积水 / 违停）。

## 六、应用价值
可降低城市巡查人力成本，提升事件响应速度，适用于社区、园区、道路等场景的常态化安全监测。
