# 参赛说明（移动云 AI Coding 大赛 · 智算方向）

> 按比赛要求填写：作品主题、所用工具/模型、创作流程、创新点。以下为模板，按需补充。

## 一、作品名称
端云协同推理平台 —— 基于边缘端 YOLOv8 与云端多模态大模型的跨域协同推理 Demo

## 二、作品主题
智算方向（跨域协同 / 模型推理优化）。面向"边缘端实时推理 + 云端深度理解"的协同范式，
将轻量目标检测放在边缘侧（CPU 即可），把复杂的语义理解交给云端多模态大模型，
实现算力在端云之间的合理分工与协同，降低整体推理成本、提升分析质量。

## 三、所用工具与技术
- 边缘推理：YOLOv8n（Ultralytics，预训练权重，本地轻量推理，CPU 可跑）
- 云端理解：移动云 / 九天大模型（多模态，OpenAI 兼容接口，使用赛事提供的 Token 算力）
- 交互界面：Gradio（Python Web Demo）
- 开发语言：Python
- AI Coding 工具：移动云湛卢原生 IDE / CodeBuddy（全流程辅助编码、测试、部署）

## 四、创作流程
1. 需求拆解：真实推理场景需要"端侧快、云侧深"的协同能力。
2. 架构设计：边缘推理层（YOLO，精确计数画框）+ 云端理解层（多模态大模型，语义报告）解耦，体现跨域协同。
3. 实现：边缘端输出中文标签与框坐标；连同原图送入云端大模型，生成"推理对象清单 / 推理研判 / 处置建议 / 结论"四段式报告。
4. 集成：Gradio 封装为可交互网页 Demo，支持上传图片一键推理。
5. 兜底：无云端 Key 时回退本地兜底报告，保证服务高可用。

## 五、创新点
- 端云协同推理范式：边缘轻量模型 + 云端大模型分工，体现智算方向的"跨域协同"。
- 推理优化：边缘侧仅用 YOLOv8n（CPU），重算力集中在云端，整体推理成本可控。
- 检测与生成解耦，兼顾精度与语义理解，两层可独立升级。

## 六、应用价值
可作为城市治理、园区巡检、工业视觉等场景的通用视觉推理底座，边缘侧快速感知、云端侧深度研判，
适合算力受限但需高质量理解的落地场景。
